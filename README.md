## 🎨 Design Philosophy

- **Swiss Brutalism**: Ultra-clean hairline border geometry, architectural monospace typography (`SF Mono`, `Fira Code`), and high-contrast warm paper palettes (`#f9f8f5`) vs obsidian black (`#080808`).
- **Zero Dependencies**: Pure Vanilla HTML5, Canvas 2D API, Web Audio API, and CSS custom properties. Zero npm packages, zero external CDNs, zero build pipelines.
- **Immediate Local & Web Compatibility**: Single-file architecture that runs natively under `file://`, on GitHub Pages, or in local Python servers without CORS friction.

## 🚀 Quickstart

### Instant Browser Launch
Clone and run immediately:

```bash
git clone https://github.com/aigroupchathq/consciousness-mechanism.git
cd consciousness-mechanism
```

Open `index.html` directly in your browser or run:

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```

Visit [`http://localhost:8000`](http://localhost:8000).
