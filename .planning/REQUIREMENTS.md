# REQUIREMENTS SPECIFICATION // THE UNEXPLORED INTERIOR

## 📋 Functional Requirements (FR)

### FR-01: Visual Awareness Suite
- Must render 5 distinct visual awareness experiments in real-time Canvas 2D at 60 FPS.
- Must capture user input timestamps and compute microsecond-accurate ignition latency.
- Must support instant tab switching with audible tactile feedback (440Hz / 660Hz chimes).

### FR-02: Phenomenal Audit Engine
- Must provide 6 responsive range sliders mapping to cognitive sovereignty vectors.
- Must render a 6-axis polygon radar chart with animated transitions.
- Must compute integrated $\Phi$ (0.00 to 1.00 bits), estimated ignition latency, and DMN rumination percentage.
- Must provide dynamic clinical classification and actionable neuro-phenomenological recovery prescriptions.

### FR-03: Cinematic Video Showcase & Export
- Must run a 6-scene automated trailer with choreography and kinetic text.
- Must support 60 FPS video recording via `MediaRecorder` API and download a valid `.webm` file.

### FR-04: Acoustic Synthesizer
- Must generate a 40 Hz Gamma binaural tone (216 Hz carrier left, 256 Hz right).
- Must include gentle lowpass filtering and click-free start/stop transitions.

## 🔒 Non-Functional Requirements (NFR)
- **NFR-01 (Zero External Dependencies)**: No third-party npm packages or external CDN dependencies.
- **NFR-02 (Performance)**: Maintain 60 FPS rendering under standard CPU/GPU loads.
- **NFR-03 (Accessibility & Responsiveness)**: Fully responsive across desktop, tablet, and mobile viewports with light and dark mode support.
